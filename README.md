# PLP Python Week 7 Assignment

## Assignment Title
Python File Handling and CSV Report Builder

## Project Files

- **my_notes.py** – Creates, writes, appends, reads, and counts notes.
- **my_notes.txt** – Stores the four notes generated by `my_notes.py`.
- **report_builder.py** – Reads learner information from a CSV file and calculates totals, passes, failures, and the average score.
- **hubs.csv** – Contains learner names, hub names, and scores.
- **report.txt** – Contains the generated learner report.
- **README.md** – Explains the project and its files.

## What happens if "a" is changed to "w"?

If `"a"` is changed to `"w"`, the file will be overwritten instead of having new information added at the end. This means the previous notes could be erased when the program writes the fourth note.
